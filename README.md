# Hanyi's Poetry Works — 含艺的诗

A beautiful website showcasing the poetry of Hanyi Zhou, built with GitHub Pages.

**Live at:** https://hkgpvg.github.io/hanyi-poem/

## Features

- Original poetry collection with beautiful typography
- Rain animation effect
- Share functionality
- Mobile-responsive design

## Tech

- HTML/CSS/JavaScript
- Hosted on GitHub Pages (project site)
